Type-Safe Configuration for Go

Load, validate, and redact configuration from files, environment variables, Kubernetes, Vault, AWS, and more — with full type safety.

Why confkit?

✓

Fully Typed

Load[T] returns your struct with full compile-time type checking. No casting, no surprises.

⚙️

Built-in Validation

Define validation rules in struct tags. min, max, required, oneof, and custom validators.

🔐

Secret Redaction

Mark fields as secret:"true" and they're automatically redacted in errors and logs.

📝

Clear Error Messages

Know exactly which field failed, why, and where it came from. Built for humans.

🔀

Multiple Sources

Mix YAML, JSON, TOML, env, flags, Kubernetes, Vault, Consul, etcd, AWS with explicit precedence.

⚡

Cloud Integrations

Optional modules for Vault, Consul, etcd, AWS. Import only what you need.

Quick Start

Load in One Call

Define your config as a Go struct. Defaults, validation, and secret redaction are just tags.

Load from YAML, environment variables, or both. confkit merges them and validates everything before returning your typed config.

type Config struct { Port int `env:"PORT" default:"8080" validate:"min=1,max=65535"` DSN string `env:"DB_URL" validate:"required" secret:"true"` } cfg, err := confkit.Load[Config]( confkit.FromYAML("config.yaml"), confkit.FromEnv(), ) // cfg is exactly type Config, fully typed

  • ✗ No redaction
